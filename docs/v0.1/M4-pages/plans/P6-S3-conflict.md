# M4/P6/S3 冲突：实施计划

上级：[P6 文档](../06-P6-source-editor.md) 3.6、3.8。

## 任务

1. `PageEditing`：409 `page.revision_mismatch` 时读当前正文，进入冲突状态（当前正文与它的 `revision`）；"保留我的"以那个 `revision` 再存，再次 409 时换成新的冲突；"放弃我的"换基准、清掉未保存。
2. `editor/conflict-view.tsx`：分包里再 `import()` `@codemirror/merge`，只读视图里的 `unifiedMergeView`；加载失败时"重试"。
3. 冲突区：`role="region"` 与标题、两个按钮；出现时焦点到标题；开着时 `Mod+S`、"保存"、`Mod+E`、"完成"只把焦点移过去。
4. 文案。

## 测试

- `PageEditing`：409 版本不一致之后读正文；保留我的用冲突时读到的 `revision`；再次 409 换新的冲突；放弃我的之后没有未保存的修改、基准是当前的。
- 组件：冲突区出现与焦点；两个按钮；开着时保存不发请求；merge 加载失败时按钮仍可用。
- 反向对照：保留我的取 409 之后的版本（而不是读到的）；放弃我的不换基准；冲突区开着时保存照发。
