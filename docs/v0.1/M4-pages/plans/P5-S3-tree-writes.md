# M4/P5/S3 树的写：实施计划

上级：[P5 文档](../05-P5-tree-reading.md) 3.7。

## 任务

1. store 的写：`create`、`rename`、`move`、`delete` 走一个 `oneAtATime` 队列，每次答复之后重读；删除 404 当作已删除。
2. 新建（"未命名 N"，409 换下一个至多三次，成功后去新页面）；改名对话框（合并的改名表单）；删除对话框（子页面数）；"移动到…"对话框（父页与位置，挡下成环与过深）。
3. 拖拽：加依赖 `@atlaskit/pragmatic-drag-and-drop` 与 `@atlaskit/pragmatic-drag-and-drop-hitbox`；`page-drag.ts` 的指令到 `NodeMove`；落点指示线；阅读者没有拖拽。
4. 文案（`field.title.*` 等）。

## 测试

- store：两个写一个接一个、每次答复之后重读、答复不在本地套用。
- 纯函数：拖拽的指令表（前、后、成为子页、拖到自己与子树、超过 10 层被挡下）。
- 组件：新建的 409 重试与三次之后的提示；改名的 422 与 409 留在表单；删除对话框的子页面数与之后的导航；"移动到…"的选项排除自己与子树、过深的父页；阅读者没有菜单与拖拽。
- 反向对照：写之后不重读；拖拽不挡成环；"移动到…"不排除子树。
