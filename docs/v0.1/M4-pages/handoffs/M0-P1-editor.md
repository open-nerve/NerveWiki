# 编辑器的遗留验证项

M0/P1 的实验 ④（[结果](../../M0-foundation/01-P1-spikes.md) 第 7 节）验证了 CodeMirror 6 与 React 19 的集成，以下三项没有覆盖，由 M4 处理。

1. **真实输入法的人工验证。** P1 只在 Chromium 上用 CDP 模拟过拼音组合输入。M4 在 Chromium、Safari、Firefox 上用真实的中文输入法各验证一遍：
   - 组合过程中不触发自动保存；
   - 组合结束后补存一次；
   - 确认后的文字与光标位置正确；
   - 组合进行中收到外部更新时不出错。

   把验证步骤写进 M4 的人工验收清单。
2. **编辑器扩展管线能否组合。** P1 的问题 4 没有回答。M4 建立"编辑器扩展管线"扩展点（总体设计 12.4）时，用 M5（锁与只读、自动保存）、M6（补全）、M7（粘贴上传）形态的示例扩展验证：能按注册顺序组合、互不干扰、可以单独卸下。
3. **编辑器分包体积。** 528 KB（gzip 183 KB），主要来自 `lang-markdown` 静态依赖的 `lang-html`。评估直接基于 `@lezer/markdown` 组装语言包、去掉 HTML 那条依赖，给出取舍。
