# M1/P5/S6 端到端（二）：实施计划

上级：[P5 文档](../05-P5-web-session.md) 3.9。

## 任务

1. A4：另起访问令牌 3 秒过期的服务；两个标签页同时保存引导的资料；续期的代数恰好 0、1、2…各一次，库中的代数与期限正确；有与没有 `navigator.locks` 各一遍（`addInitScript` 删除 `Navigator.prototype.locks`）。
2. A5：测试用页面的刷新令牌先续期，页面刷新之后回到登录页、记录被删；控制台只有那一条 401。
3. A6：一个标签页退出两个都到登录页；另一个标签页写入别的账户的记录，第一个跟着换，旧会话不被吊销；退出之后另一个标签页登录，两个都跟上。
4. A9：引导的页面版本。
5. README：前端的登录、会话与引导。
6. 浏览器实测：局域网地址的 HTTP 两个标签页（租约）；两个配置文件、两个账户各两个标签页。记入第 7 节。

## 测试

- `make e2e` 全部通过；`--repeat-each 3` 与 `--workers 1` 各一轮。
- 反向对照：续期锁换成空锁 → A4 失败；退出不删记录 → A6 失败。
