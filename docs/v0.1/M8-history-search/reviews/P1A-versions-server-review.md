## 反向对照

- 用例（`page/app`）：28 处改坏（区间的核对、倒序、`editing`、码的次序、`Kind`、显示名、游标的上下限、预算的释放等），都被测试抓到。
- 数据库与规则：17 处（`ListVersions` 的上界、倒序、只列这一页；`FindVersion` 的下界、只找这一页、正文；`AliveChangesetOf` 的期限与已结束的会话；`FindAnyNode` 的 `deleted_at`；`reverts_id` 的写与读；版本链的守卫与 0 行的错误；唯一索引；`reverts_id` 的检查；两条权限规则），都被抓到。
