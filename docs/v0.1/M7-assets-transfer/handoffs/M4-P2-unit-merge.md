# 一个单元里先建后删的节点

导入若在一个写入单元里先建一个节点、再把它删掉（例如去重或回滚一部分），合并之后的条目与改动前后都为空，条目表的检查拒绝它、事件里多一个空的改动。做法与 M9 的 batch 相同，见 [M9 的移交](../../M9-mcp/handoffs/M4-P2-unit-merge.md)；先到的那个 M 定下，另一个照用。
