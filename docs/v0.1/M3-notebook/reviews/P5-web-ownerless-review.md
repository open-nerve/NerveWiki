## 发现与处置

| # | 级别 | 发现 | 处置 |
|---|---|---|---|
| M1 | Major | 接管、删除对已不是工作区管理员的账户，服务端答 404 `notebook.not_found` 而不是 403（`lockOwnerless` 把 `Forbidden` 并进未找到，OpenAPI 与 N9 同此）：页面处理 403 的分支永远走不到，它的测试靠假服务端答真实服务端答不出的 403 才通过。被降级的管理员点"接管"看到"已经不是无主的了"（不实），行消失，重读清单答 403 被吞掉（store 已有数据时 SWR 的错误看不见），直到窗口下一次取得焦点才跟上角色 | 接管、删除答 404 时重读清单、审计与工作区列表（角色变了，页面随之说明"只有管理员能看"）；去掉 403 的分支。三处只给管理员的读（无主页的清单、审计、首页提醒）以 `app/follow-role.ts` 的 `useFollowRole` 为 `onError`：答 403 时重读工作区列表。测试改为假服务端在降级的同时答 404；清单、审计、提醒各一个读答 403 的测试（经应用内导航，工作区列表不随焦点重读）。R4、R6a–c 让它们失败 |
| M2 | Major | `load` 在等待之前就递增 `series`：第一页重读在途时点"加载更多"，`more` 取到新的 `series` 与旧的 `nextCursor`；重读先答时，旧游标的一页接在新的第一页之后、不被丢弃，键集游标留下新事件数那么多条的缺口，之后的游标沿旧链，缺口一直在。窗口取得焦点（SWR 的 `revalidateOnFocus`）或接管、删除之后紧接着点"加载更多"即可触发 | 一页只在答复时它的游标仍是 `nextCursor` 才接上（两种先后、重读失败都对）；在途的一页记下自己的游标（N1）。另随 Q2：重读的第一页的最后一条在已有的事件里时，保留其后的事件与游标，焦点不再收起"加载更多"读出的页；接不上或第一页已是最后一页时整体替换。store 测试：四种交错、接得上、接不上、N1。R1–R3 让它们失败 |
| m1 | Minor | 无主页测试的假服务端与真实的不同：接管答 `member_count: 1`，测试因此断言进"我的笔记本"；真实服务端对还有一位成员的笔记本答 2（`take_over.go` 接管之后计数），是团队笔记本（e2e N9 断言的正是这个）；假的笔记本列表不含接管的那一本 | 假服务端答接管之后的成员数、列表里的开放程度与 `admin`，并把它加进笔记本列表；断言改为"团队笔记本" |
| m2 | Minor | 测试缺口：`load` 在途时的 `more`（M2）；"接管"双击只发一次（设计 3.3"一次只发一个"，只测了 store 的队列）；13.2 第 15 条的按工作区页面测试（从一个工作区的页面直接到另一个的，各读各的），无主与审计都没有（P4 的笔记本列表也没有） | 全部补上：store 的交错；双击加再点一次只发一个（答复按住，R8 让它失败）；无主页从 Lab 到 Acme 清单与审计各读各的（R9、R9b 让它失败）；笔记本左栏同样补一个（`notebook-nav.test.tsx`，R10 让它失败） |
| N1 | Nit | 重读之后、旧一串的一页还在途时点"加载更多"，返回的是那个旧的承诺，它的页随后被丢弃，这次点击什么都没做 | 随 M2：游标不同时另发一页（R3） |
| N2 | Nit | 404 意味着别的管理员动过或已归还，各有审计记录，却只重读清单 | 随 M1：404 时也重读审计（R5） |

## 疑问与判断

| # | 疑问 | 判断 |
|---|---|---|
| Q1 | 服务端把"不是管理员"并进 404，404 的文案与处理是否把角色变化算作原因之一 | 处理上算（M1：重读工作区列表）；文案不改：角色变了的页面随即换成"只有管理员能看"，那句说明看不到 |
| Q2 | 每次窗口取得焦点都重读审计的第一页，收起"加载更多"读出的页；是保留接得上的尾部，还是关掉焦点重读 | 保留接得上的尾部（M2 的处置）：焦点重读照样带来别的管理员的新记录，已读的位置不丢；接不上时整体替换 |
| Q3 | "一次只发一个"指同一本还是整个清单 | 同一本（N4） |
| Q4 | 键集服务端的同一串页不会重叠，`more` 按 id 去重永远不触发；留作防御还是删去 | 留：列表以 id 为 React 的 key，重复会出错；保留尾部与在途页的路径是新的，去重是它们的兜底 |
| Q5 | 作者列出的七处偏差 | 审查者都同意：接管以答复把笔记本放进列表（`receive`，答复是权威的，`put` 计为写答复，重叠的读被丢弃）；`auditEvents` 不带 `limit`；移出的说明对移出者说"你"；非管理员看到"工作区的管理员可以接管它"；`anotherPage` 与 `newOnboardedTeam`；N8 的停用拒绝单独成测试；N10 的 51 条记录（只有这样才在真实页长下走到"加载更多"） |
