# M3/P4/S3 笔记本设置：实施计划

上级：[P4 文档](../04-P4-web-notebooks.md) 3.4。

## 任务

1. `app/role-menu.tsx`：`RoleMenu` 按角色列表与文案键通用，工作区的成员行改用它。
2. `pages/notebook/general-page.tsx`、`access-options.tsx`：改名（`RenameForm` 的写法）、开放程度（单选与保存）、删除（输入名称）；非管理员只读。
3. `pages/notebook/members-page.tsx`、`notebook-member-row.tsx`：成员（角色菜单、移出）、添加（候选、角色、成功的提示、422）、离开（只给显式成员，`texts`）。添加、移出之后重读笔记本列表；改角色失败时重读成员与笔记本列表。
4. 文案。

## 测试

- 常规页：管理员改名（只在变化时发、草稿保留）、改开放程度、删除之后回到工作区首页；非管理员只读。
- 成员页：列表（访客看不到邮箱）、自己一行没有控件、添加（候选排除已是成员的、成功、`not_allowed` 与 `duplicate` 重读）、改角色（失败时重读）、移出（焦点到本节标题）、离开（只给显式成员、409 说明、离开之后看不到回到首页、仍看得到留下）。
- 两种 SWR 测试（读不到与重读）。
- 反向对照：离开给非显式成员 → 测试失败；添加之后不重读笔记本列表 → 分组的测试失败。
