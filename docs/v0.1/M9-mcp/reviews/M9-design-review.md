## 负责人 2026-10-17 的决定（背景）

初稿据以写成，审查不改它们（00 号文档第 11 节的前四条）：

1. 历史对 agent 只读：agent 读日志、单个变更集与版本；整组撤销、还原版本、从回收站恢复是人在网页上的动作；`batch` 的变更集仍要能在网页上整组撤销，所以 M9 实现多轮应用与临时名称（M8/P3 的移交）与跨批的那一项（M8/P4 的移交）；v0.1 里 MCP 不开后台任务。
2. 编辑锁：MCP 的写是一次性的，没有编辑会话；正被网页编辑的页（包括本人自己的编辑器）拒绝 MCP 的写，答 `page.locked` 并说出是谁持锁；agent 不能接管。
3. `AGENTS` 页：笔记本根下标题为 AGENTS 的页，按标题键找；去掉 frontmatter 的正文是说明，约 32 KB 截断；没有时给内置的简短说明；缓存的键经得起替换、改名、恢复（G16）。
4. 工具与入口：`grep` 之外加 `search`；接入写进 Claude Code 与 Codex 的文档；网页上显示 MCP 地址的界面等 v0.1 之后的打磨。
