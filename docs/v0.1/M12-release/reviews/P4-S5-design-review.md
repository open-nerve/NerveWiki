## 重叠

- P4S5A-M2 与 P4S5B-I1 是同一处（被拒的网址交回 `Autolink` 重扫）：A 量的是路径前被拒（`www.a.b_/`，lezer 自己就平方、不在被拒的记下里），B 量的是同一个域名上的一串起点（`www.a.`、`-www.a`）。两种都不再交回；B 的那一种另记下拒的理由（决定 527），A 的那一种由 4.1 第 2 条之二守"不比没有扫描时慢"。
- P4S5C-I1 与 P4S5A 的"`m3`、`m5` 设计的随机文档没抓住"是同一件：生成器坏了。修好之后 `m3` 被随机文档抓住（C）；`m5` 仍靠手写文档（随机文档走到"修掉 `)`"8,195 次，但成对的括号太稀）。
- P4S5C-I2 的 x8 与 P4S5A-M1 都在 `<?` 的电子邮件一支：M1 改了它的写法（整个正则试一次），x8 的手写文档照样守。
- P4S5B-N3 与 P4S5A 的未核实 2 都在 1.5 的读数上：1.5 照第一次修订重量。
- P4S5C-M3 与 P4S5B-N5 都在 P4/S2 修好的脚本上：4.2 一并写。
