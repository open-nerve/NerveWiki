## 主持者的决定

- **572 重类的四个词照设计，不提高目标；份数与 M8 的最大交 S3 判读**（审查 A 的 Q1，`fix-1.md`；份数照核对 A 的 N3）：语料是设计审查与修订核对定下的，提高 `中国`（或整个中文重类）的目标就改了 B1 与 M8 的同口径，还会挪动所有页的补放、sha256 与 10.1 的数要重写，收益不确定（A 也倾向不改）。四个词在 3,000 页上 150、150、150、152 页；补放之前自然出现的 15、58、37、152 页（3 万页上 155、540、381、1,580），即 `中国`、`ai`、`kernel` 自然只在约 0.5%、1.9%、1.3% 的页，补放到 5% 的下限（`中国` 九成是补放的），`linux` 自然约 5.2–5.4%，一页也没补放。四个都只在约 5% 的页，不是真语料里"最常见"的键。S3 量 B1 时把这四个词的份数与 M8 记下的最大（719、827.2 ms）一起列出，判第 1 步时考虑这几格偏轻（P4 设计 3.6 的 B1）；第 2 步对照 `308eafc6` 用同一份语料，不受影响。

- **575 驱动到期只停发，在途的答完再汇总，排空至多 60 秒、不加 `-drain`；截断与失败分开数**（审查 B 的 M1、M2，`fix-1.md` 取 B 的建议；审查 C 对小决定第 4 条的建议；核对 C 的 M5 = B 的 N6，`fix-2.md` 取 C 的 (a)）：到期取消在途的请求，被截的是更长的那些，另数也压低 p50、p99（B 的病态一轮截了 12%），还让假服务端读到被取消的上传（B 的 M1）。`-for` 到期停发；每个循环发每个请求之前看期限（核对 B 的 M7，`d5756213`），编辑者只关会话；在途的等到 `drive.DefaultDrain`，超了才截断、记 `cut`；汇总分开数 `cut=`（到期截断的）与 `errors=`（传输里失败的），另记 `cut_longest=`，有 `errors` 时命令失败（`94ff27e5`）。不加开关：60 秒已是 serve 自己的请求期限 15 秒的四倍，没有要调的场合；报告与草稿原写成命令行的 `-drain`，命令行没有它。

## 实施中定的

实施报告第 7、8 节与修复两轮（三位审查者各在自己的范围里判过，主持者接受，决定 578）。与设计不同的在 [P4 设计](../04-P4-performance.md) 3.10 逐条列出：
